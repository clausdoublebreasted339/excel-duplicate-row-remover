Find and remove duplicate rows in Excel spreadsheets by selected columns. Works with .xlsx and .csv - no Excel installation required. Generates a removal report.

## Features

- Select which columns define a duplicate row
- Keep first occurrence, last occurrence, or flag all duplicates
- Supports .xlsx, .xls, and .csv file formats
- Microsoft Excel installation not required
- Generates a report listing all removed rows

## FAQ

**Does it require Microsoft Excel?**  
No. The tool reads and writes Excel files independently.

**Can I choose which column to check for duplicates?**  
Yes, select any combination of columns as the deduplication key.
